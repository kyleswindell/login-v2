# Open Loops

Use this file for non-canonical, multi-session open loops that are useful to remember outside the active workflow state owner.

Do not use this file for:

- active workflow queue/state
- canonical planning truth
- branch integration handoff records

## Format

For each loop, record:

- loop
- owner or likely workflow
- current status
- next action
- canonical links
- review after

## Loops

- none recorded
