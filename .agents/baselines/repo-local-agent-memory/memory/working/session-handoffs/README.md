# Session Handoffs

Use this directory for concise, non-canonical session handoff notes that should outlive one chat session but do not belong in active workflow state or dedicated branch-handoff owners.

## Use Cases

- planning or research handoff between sessions
- memory-backed continuation notes
- non-batch investigation continuity

## Do Not Use For

- `<branch-handoff-root>`
- `<active-workspace-root>`
- canonical docs decisions or status truth

## Suggested Fields

- session
- date
- scope
- current state
- next step
- canonical links
