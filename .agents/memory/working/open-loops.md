# Open Loops

Use this file for non-canonical, multi-session open loops that are useful to remember outside the active batch workspace.

Do not use this file for:

- active batch queue state
- canonical planning truth
- worker integration handoff records

## Format

For each loop, record:

- loop
- owner or likely workflow
- current status
- next action
- canonical links
- review after
