# Session Handoffs

Use this directory for concise, non-canonical session handoff notes that should outlive one chat session but do not belong in active batch state or worker-branch handoff artifacts.

## Use Cases

- planning or research handoff between sessions
- memory-backed continuation notes
- non-batch investigation continuity

## Do Not Use For

- `.agents/batch-branch-handoffs/`
- `/docs/08-active/`
- canonical docs decisions or status truth

## Suggested Fields

- session
- date
- scope
- current state
- next step
- canonical links
