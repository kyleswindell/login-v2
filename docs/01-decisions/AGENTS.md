# docs/01-decisions AGENTS.md

## Purpose

Decision records only. This branch owns ADRs and elevated decisions that constrain future work.

## Read Order

1. Read `index.md` to identify the relevant decision.
2. Open only the ADR or decision record that governs the current task.

## Avoid

- Do not duplicate decision summaries into other branches.
- Do not infer new rules from planning notes when an ADR is required.
- Do not edit this branch during implementation unless the task explicitly changes a durable decision.
