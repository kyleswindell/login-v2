# docs/02-standards AGENTS.md

## Purpose

Rules only. This branch owns standards for coding, documentation, database, security, logging, and UI behavior.

## Read Order

1. Read `index.md` to locate the relevant standard area.
2. Open only the standard file tied to the task.
3. For UI work, prefer the specific component contract over broad UI standards.

## Avoid

- Do not read every UI standard by default.
- Do not move architecture, feature behavior, execution flow, or planning status into this branch.
- Do not load research/reference files when a standards contract already answers the question.

## Long Files

- `ui/components/Tier 2 Pattern Library Checklist.md` is now a hub. Use its linked `tier-2-patterns/` child files for focused Tier 2 reads.
- Documentation research belongs in `docs/09-reference/` unless it has been promoted into a rule here.
