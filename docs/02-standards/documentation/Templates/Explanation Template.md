# Explanation Template

Use this for rationale-oriented docs that explain why the system works a certain way.

```md
# Topic

## Problem Statement

What confusion or design pressure this resolves.

## Context

Technical and organizational constraints.

## Reasoning

Tradeoffs, alternatives considered, and why this approach was chosen.

## Consequences

Operational or maintenance implications.

## Related Decisions

Links to ADRs, RFCs, release notes, or feature docs.

## Related
```
