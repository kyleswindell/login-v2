# Feature Spec Template

Use this when planning or documenting a user-facing capability.

```md
# Feature Name

## Purpose

What problem this feature solves.

## Scope

What is included and excluded.

## User / Admin Workflows

Main flows this feature must support.

## Data Model

Tables, options, files, JSON payloads, or API contracts.

## Permissions / Security

Who can view or change the feature.

## Tenant Considerations

How tenant isolation, configuration, and sync behave.

## Validation

Server-side validation and manual/automated test expectations.

## Rollout Notes

Deployment, migration, or release notes.

## Related
```
