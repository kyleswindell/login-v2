# Reference Template

Use this for precise lookup docs such as components, APIs, config, folders, tables, commands, or schemas.

```md
# Component / API / Config Name

## Summary

One paragraph: what it is, and what it is not.

## Interface

Public endpoints, functions, events, CLI commands, or config schema.

## Parameters / Fields

Use tables when possible. Include types, defaults, and constraints.

## Examples

Short, copy-pastable, tested examples.

## Version Notes

Breaking changes and deprecations. Link to release notes or ADRs when relevant.

## Related
```
