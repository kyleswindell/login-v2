# Runbook Template

Use this for repeatable operational procedures.

```md
# Runbook Name

## Purpose

What this runbook helps operators do.

## When To Use This

Symptoms, schedules, or triggers.

## Before You Start

Permissions, backups, and safety checks.

## Procedure

1. First step.
2. Second step.
3. Third step.

## Validate

How to confirm success.

## Rollback / Recovery

What to do if the procedure fails.

## Related
```
