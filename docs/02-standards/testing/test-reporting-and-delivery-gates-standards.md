# Test Reporting And Delivery Gates Standards

Parent: [Testing Standards Index](index.md)

This document is superseded and remains only as a compatibility route for existing references.

Use the [Reporting And Testing Gates Standards Index](reporting-and-gates/index.md).

## Verification Reporting And Artifacts

Use [Verification Reporting And Artifact Standards](reporting-and-gates/verification-reporting-and-artifact-standards.md) for:

- execution records;
- structured reports;
- evidence manifests;
- report and protected-path hashes;
- manual and specialist evidence;
- failed-proof reporting;
- storage and retention;
- evidence redaction;
- concise issue and pull-request summaries.

## Testing Gates

Use [Testing Gate Standards](reporting-and-gates/testing-gate-standards.md) for:

- preimplementation testing evidence;
- development and pull-request testing evidence;
- merge-candidacy testing completeness;
- release and deployment testing gates;
- post-deployment proof;
- flaky, skipped, and incomplete proof handling;
- final testing-acceptance completeness.

Proof-state and initial-proof meanings remain with the [Verification Contract Standards Index](verification-contract/index.md).

Do not add new reporting or testing-gate policy to this compatibility file.
