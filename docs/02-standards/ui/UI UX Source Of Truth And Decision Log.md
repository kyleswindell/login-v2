# UI UX Source Of Truth And Decision Log

This document defines the canonical scope and intent for UI UX Source Of Truth And Decision Log.

## Purpose

Define the canonical external guidance hierarchy and adaptation rules for Login App 2.0 UI/UX standards.

This note is the canonical owner for UI/UX source-of-truth policy in App 2.0 docs.

## External Source Baseline

Primary design references for this program:

- Material Design (M2 request scope): `https://m2.material.io`
- Material Design static docs archive: `https://m1.material.io`
- IBM Carbon Design System: `https://carbondesignsystem.com`

## Adaptation Hierarchy

When guidance conflicts, apply this precedence order:

1. product constraints and accessibility requirements for Login App 2.0
2. locked stack and architecture constraints in canonical V2 docs
3. Carbon accessibility and enterprise rigor patterns
4. Material system guidance (interaction and visual model)
5. local historical styling conventions

## Decision Governance Rules

- Canonical UI rules must be published in `02-standards/ui/` notes only.
- Research notes, implementation history, and rollout tracking belong in `09-reference/ui/`.
- Any change to source interpretation that affects enforceable UI behavior must update the relevant canonical standards note in the same work cycle.
- Canonical and planning notes must remain cross-linked when planning is still active.
