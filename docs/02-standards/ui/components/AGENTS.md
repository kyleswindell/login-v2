# docs/02-standards/ui/components AGENTS.md

## Purpose

UI component library and pattern coverage guidance. This folder supports Tier 1 implementation tracking and Tier 2 pattern planning.

## Read Order

1. For Tier 1 implementation status, read `Tier 1 Component Implementation Checklist.md`.
2. For Tier 2 planning, read `Tier 2 Pattern Library Checklist.md` as the hub, then open only the relevant `tier-2-patterns/` family file.
3. For taxonomy questions, read `UI UX Component Taxonomy And Coverage Matrix.md`.

## Avoid

- Do not read every Tier 2 family file when the task targets one pattern.
- Do not put component behavior rules here when a contract file should own them.
- Do not mix implementation inventory with canonical component contracts.

## Split Guidance

Tier 2 details are split by pattern family under `tier-2-patterns/`. Keep new Tier 2 rules in the narrow family file and update the hub/index when adding families.
