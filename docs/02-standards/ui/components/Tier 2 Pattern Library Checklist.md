# Tier 2 Pattern Library Checklist

This document is the canonical Tier 2 pattern-library hub. Detailed pattern-family checklists live in focused child files so implementation and review agents can read only the family they are changing.

## Purpose

Define the implementation checklist for reusable Tier 2 UI patterns composed from Tier 1 primitives.

This checklist is the implementation-facing companion to the component taxonomy, Tier 1 checklist, and current UI component library standards.

## Read Guidance

For a narrow implementation or review task:

1. Read this hub.
2. Read [Tier 2 Pattern Boundary And Validation](tier-2-patterns/boundary-and-validation.md) only when tier ownership or validation is unclear.
3. Read only the pattern-family file tied to the component or route being changed.

Do not load every Tier 2 pattern-family file unless the task is a full Tier 2 audit.
