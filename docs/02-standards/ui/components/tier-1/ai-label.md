# AI Label T1 Standard

UI Reference route: `/platform/ui-reference/components/ai-label`

## Purpose

AI label identifies AI-assisted content only when an AI-assisted feature exists.

## Required UI Reference Display

- queued trigger condition
- not-applicable status
- implementation owner and queued gaps

## Usage Rules

- Do not build speculative AI chrome.
- Add implementation only after an AI feature creates a concrete need.
