# Button T1 Standard

UI Reference route: `/platform/ui-reference/components/button`

## Purpose

Button owns primary, secondary, low-emphasis, and destructive action behavior.

## Required UI Reference Display

- standard, soft, ghost, outline, danger, disabled, loading, and focus states
- all supported semantic colors
- implementation owner and queued gaps

## Usage Rules

- One primary action per region.
- Use action tokens, not raw color utilities.
