# Checkbox T1 Standard

UI Reference route: `/platform/ui-reference/components/checkbox`

## Purpose

Checkbox represents independent choices and multi-select groups.

## Required UI Reference Display

- checked, unchecked, indeterminate queued, focus, disabled, read-only, error, and warning states
- independent choice and multi-select group examples
- checkbox versus radio usage boundary

## Usage Rules

- Use for multiple or independent selections.
- Do not use for one required mutually exclusive choice.
