# Data Table T1 Standard

UI Reference route: `/platform/ui-reference/components/data-table`

## Purpose

Data table presents tabular data with column alignment, sorting, filtering, and row actions.

## Required UI Reference Display

- basic, selectable, sortable, loading, empty, and row action states
- table cell spacing behavior
- implementation owner and queued gaps

## Usage Rules

- Use for many rows or sortable/filterable data.
- T2 table pages compose this owner.
