# Date Picker T1 Standard

UI Reference route: `/platform/ui-reference/components/date-picker`

## Purpose

Date picker owns date and date-time entry behavior.

## Required UI Reference Display

- date, date-time, range queued, error, warning, disabled, and read-only states
- spacing and validation behavior
- implementation owner and queued gaps

## Usage Rules

- Use native controls for simple date entry until calendar/range controls are approved.
