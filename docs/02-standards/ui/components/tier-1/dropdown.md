# Dropdown T1 Standard

UI Reference route: `/platform/ui-reference/components/dropdown`

## Purpose

Dropdown presents known options and menu-like selection boundaries.

## Required UI Reference Display

- default, disabled, error, warning, and searchable handoff states
- select versus dropdown versus multiselect boundary
- implementation owner and queued gaps

## Usage Rules

- Use select for short lists and searchable select for long known lists.
