# Form T1 Standard

UI Reference route: `/platform/ui-reference/components/form`

## Purpose

Form represents the primitive field grouping boundary while T2 owns full form composition.

## Required UI Reference Display

- section, inline row, summary, and actions disposition
- link to T2 Form Patterns
- implementation owner and queued gaps

## Usage Rules

- T1 field pages own primitives.
- T2 Form Patterns owns compositions.
