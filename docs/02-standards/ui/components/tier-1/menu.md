# Menu T1 Standard

UI Reference route: `/platform/ui-reference/components/menu`

## Purpose

Menu displays contextual actions in a disclosure list.

## Required UI Reference Display

- enabled, hover, focus, selected/current, danger, disabled, divider, and submenu boundary states
- keyboard and mouse expectations
- implementation owner and queued gaps

## Usage Rules

- Use menu items and dropdown-action-menu for grouped contextual actions.
