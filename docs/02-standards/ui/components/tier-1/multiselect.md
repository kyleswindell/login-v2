# Multiselect T1 Standard

UI Reference route: `/platform/ui-reference/components/multiselect`

## Purpose

Multiselect selects multiple known options in a compact control.

## Required UI Reference Display

- queued, tagged values queued, and filtering queued states
- select versus dropdown versus checkbox boundary
- implementation owner and queued gaps

## Usage Rules

- Use checkbox groups for small visible sets until a dedicated multiselect consumer exists.
