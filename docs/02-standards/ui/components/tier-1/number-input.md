# Number Input T1 Standard

UI Reference route: `/platform/ui-reference/components/number-input`

## Purpose

Number input handles constrained numeric entry and small increment changes.

## Required UI Reference Display

- default, fluid, min/max/step, error icon, warning icon, disabled, read-only, and focus states
- keyboard behavior
- implementation owner and queued gaps

## Usage Rules

- Use for small relative numeric adjustments.
- Use text input or slider for wide ranges.
