# Radio Button T1 Standard

UI Reference route: `/platform/ui-reference/components/radio-button`

## Purpose

Radio button represents mutually exclusive single-selection groups.

## Required UI Reference Display

- vertical, horizontal, selected, unselected, focus, disabled, read-only, error, and warning states
- helper text and group state behavior
- checkbox versus radio boundary

## Usage Rules

- Use for one choice from a visible set.
