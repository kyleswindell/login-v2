# Structured List T1 Standard

UI Reference route: `/platform/ui-reference/components/structured-list`

## Purpose

Structured list presents scannable row comparison and selectable rich options.

## Required UI Reference Display

- default, selectable, condensed, hang alignment, flush alignment, selected, focus, disabled, and skeleton states
- density and alignment behavior
- implementation owner and queued gaps

## Usage Rules

- Use data table for sorting/filtering or multiple row selection.
