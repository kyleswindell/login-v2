# Tabs T1 Standard

UI Reference route: `/platform/ui-reference/components/tabs`

## Purpose

Tabs switch between peer content panels.

## Required UI Reference Display

- line, contained, vertical, icon-leading, icon-only, overflow, selected, focus, and disabled states
- tabs versus progress/comparison guidance
- implementation owner and queued gaps

## Usage Rules

- Do not use tabs for progress or comparison tasks.
