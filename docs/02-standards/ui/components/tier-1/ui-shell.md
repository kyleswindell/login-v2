# UI Shell T1 Standard

UI Reference route: `/platform/ui-reference/components/ui-shell`

## Purpose

UI shell defines the application shell family: header, left panel, right panel disposition, account menu, notification handoff, and global actions.

## Required UI Reference Display

- header, left panel, right panel queued, desktop, mobile, account menu, and notification handoff sections
- T2 navigation/layout ownership links
- implementation owner and queued gaps

## Usage Rules

- T2 layout and navigation pages own shell composition.
- Header, left panel, and right panel remain Login-specific subsections of the UI shell family.
