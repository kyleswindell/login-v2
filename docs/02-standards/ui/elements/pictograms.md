# Pictogram Foundation Standard

## Purpose

Define the disposition for large illustrative symbols used outside normal UI icon scale.

## Current Implementation

No pictogram library is approved for Login App 2.0.

## UI Reference Route

`/platform/ui-reference/elements/pictograms`

## Required Visible Examples

- queued trigger condition
- minimum size guidance
- not-a-UI-icon replacement guidance

## Usage Rules

- Pictograms are not replacements for UI icons.
- Use pictograms only when empty, onboarding, blocked, or explanatory states need a larger visual anchor.
- Do not import Carbon pictograms without a separate decision record.

## Queued Gaps

- Asset source, licensing, and style direction are queued until a real feature requires pictograms.

## Carbon Comparison Notes

Carbon pictograms are a useful category reference. Login App does not currently adopt Carbon pictogram assets.
