## Layer Requirements

- Element tests enforce global API boundaries across Components and Patterns.
- Element governance scans must classify consumer values as approved token API, approved structural exception, deferred/blocked gap, or failure.
- Element tests should not assert component-specific behavior beyond the Element API boundary.
- Broad allowlists are prohibited; exceptions must be narrow by path, property, value, and reason.
