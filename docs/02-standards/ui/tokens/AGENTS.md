# docs/02-standards/ui/tokens AGENTS.md

## Purpose

UI token rules, especially color and theme-token governance.

## Read Order

1. Open the specific token standard affected by the task.
2. Cross-check component contracts only when token usage changes component behavior.

## Avoid

- Do not introduce new tokens from implementation code without standards ownership.
- Do not read all UI standards for a narrow token lookup.
- Do not treat reference palettes as approved tokens unless this folder adopts them.
