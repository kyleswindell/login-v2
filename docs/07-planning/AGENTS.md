# docs/07-planning AGENTS.md

## Purpose

Sequencing and intent only. This branch owns roadmap, phase plans, batch plans, dependency sequencing, and implementation intent.

## Read Order

1. Read `index.md` for planning navigation.
2. Read `roadmap.md` only for phase-level status or sequencing questions.
3. Open the exact phase or batch planning file for the current scope.

## Avoid

- Do not read all phase plans for implementation work.
- Do not place durable architecture, feature behavior, schema, or runbook truth here.
- Do not use planning notes as a substitute for canonical owner docs when making implementation decisions.

## Long Context Guidance

Planning files can be large because they include sequencing context. Prefer heading search and scoped section reads over full-file reads.
