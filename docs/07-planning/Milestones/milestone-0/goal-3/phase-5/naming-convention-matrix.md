## 1. Purpose

Provide one concise lookup for naming a material Login 2.0 artifact from its owner, subject, Technical Role, identifier family, placement, and compatibility status.

## 2. Status

- Matrix lifecycle: planned
- Decision source: Decisions 5.1 through 5.14 accepted through repository-owner Phase 5 review
- Implementation state: target direction only
- Owning GitHub issue: [#52](https://github.com/kyleswindell/login-v2/issues/52)

## 3. Use This Matrix For

Use this matrix to:

- select the applicable naming family;
- identify the canonical pattern and a valid example;
- reject common generic or cross-family names;
- locate the detailed Phase 5 decision;
- identify compatibility treatment or later authority.

## 4. Do Not Use This Matrix For

Do not use this matrix to:

- infer one identifier family automatically from another;
- determine final Core owner decomposition;
- classify every current repository artifact;
- authorize physical renames or aliases;
- design detailed database identifiers;
- replace the detailed Phase 5 decisions, ADR-0007, or applicable standards.
