# docs/07-planning/phases AGENTS.md

## Purpose

Phase-level sequencing and implementation intent. This folder owns phase indices and phase-scoped planning notes.

## Read Order

1. Open the active or named phase folder first.
2. Read that phase's index before individual planning notes.
3. Open only the batch or planning file for the current phase scope.

## Avoid

- Do not read every phase folder for a current-phase task.
- Do not use phase plans as canonical feature, architecture, database, or runbook truth.
- Do not update parent phase status from a batch unless the active workflow owns that sync.

## Split Guidance

Phase folders should remain phase-scoped. If a planning file becomes a mixed backlog, split it into phase index, batch plan, deferment list, and handoff note rather than expanding one file indefinitely.
