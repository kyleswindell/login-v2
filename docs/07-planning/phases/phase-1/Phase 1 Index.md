## Promotion Rule

Once a planning area becomes stable enough to be treated as canonical, its content should be promoted into the appropriate permanent note under one of these branches:

* `docs/03-architecture/`
* `docs/04-features/`
* `docs/09-reference/`
* `docs/10-runbooks/`

The planning note should then remain as lightweight planning history and link to the permanent owner.
