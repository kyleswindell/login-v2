## 2. Scope

### 2.1. Belongs Here

This folder may contain temporary planning for:

* Laravel framework integration;
* application bootstrap and composition;
* root Laravel folder roles;
* owner-local Laravel conventions;
* providers and registration;
* routes and delivery integration;
* configuration;
* console and scheduled execution;
* persistence integration;
* resources and tests;
* placement, naming, migration, and compatibility.

### 2.2. Does Not Belong Here

This folder does not contain:

* the canonical Laravel definition;
* Core, Module, UI, or Surface definitions;
* feature behavior;
* implementation code;
* permanent architecture after promotion;
* unrelated temporary notes;
* active issue or Project status.
