## 2. Scope

### 2.1. Belongs Here

This folder may contain temporary planning for:

* Surface composition;
* Surface classification;
* interactive and non-interactive Surface models;
* Surface-specific adapters;
* placement and dependency rules;
* naming conventions;
* representative validation;
* migration and compatibility direction.

### 2.2. Does Not Belong Here

This folder does not contain:

* the canonical Surface definition;
* Core, Module, or UI definitions;
* implementation code;
* permanent architecture after promotion;
* unrelated temporary notes;
* active issue or Project state.
