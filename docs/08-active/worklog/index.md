# Worklog Index

Tracks all work passes for the active batch.

---

## Entries

| ID         | Date       | Pass Goal       | Status  | Commit | Deploy | Notes           |
| ---------- | ---------- | --------------- | ------- | ------ | ------ | --------------- |
| <P-B-####> | MM-DD-YYYY | <short summary> | PARTIAL | Yes    | Yes    | <optional note> |

---

## Status Definitions

- **IN_PROGRESS** → work pass ongoing
- **PARTIAL** → completed but pending review or follow-up
- **READY_FOR_REVIEW** → ready for manual review
- **BLOCKED** → cannot proceed due to issue

---

## Rules

- Add a new row for every worklog file created
- Do NOT edit historical entries except to correct factual errors
- Status must reflect actual state, not assumptions
- Keep entries short and scannable
