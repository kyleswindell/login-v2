# docs/09-reference AGENTS.md

## Purpose

Non-canonical support only. This branch owns research, matrices, inventories, external references, and supporting material.

## Read Order

1. Read `index.md`.
2. Open the exact reference file named by the task or by a canonical doc.
3. Prefer tables, summaries, and headings before reading full research prose.

## Avoid

- Do not promote reference material to canonical truth without updating the canonical owner branch.
- Do not read long research files during routine implementation unless the task depends on their evidence.
- Do not treat external reference findings as current rules unless a standards or decision doc adopts them.

## Long Files

Research and audit files may be intentionally long. Use targeted search and section reads.
