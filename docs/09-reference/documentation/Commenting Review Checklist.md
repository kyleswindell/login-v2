# Commenting Review Checklist

This document defines the canonical scope and intent for Commenting Review Checklist.

## Purpose

Support checklist for review passes against canonical commenting standards.

## Checklist

- can the comment be replaced with clearer code?
- does the comment explain why, not just what?
- is the comment still true after the change?
- does any TODO link to durable context?
- is commented-out code absent?
- are PHPDoc blocks adding useful contract/static-analysis value?
