# docs/09-reference/ui AGENTS.md

## Purpose

UI support material: audits, matrices, inventories, external references, and implementation support notes.

## Read Order

1. Read `index.md`.
2. For current UI Reference route questions, open the route disposition or starter catalog matrix named by the task.
3. For audit evidence, search within the audit file for the specific component, gap ID, or queue ID.

## Avoid

- Do not read full audit files during routine implementation.
- Do not treat reference matrices as standards unless `docs/02-standards/ui/` adopts the rule.
- Do not duplicate reference findings into canonical docs without moving only the durable rule or decision.

## Split Guidance

Large audits should be split by component family or evidence area after the review/finding cycle closes. Keep a short index file that maps gap IDs to split files.
