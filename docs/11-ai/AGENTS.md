# docs/11-ai AGENTS.md

## Purpose

AI governance only. This branch owns agent-governance rules, active document reviews, workflow correction records, and AI-facing documentation policy.

## Read Order

1. Read `index.md` for AI-governance navigation.
2. Open `rules.md` for durable AI-governance rules.
3. Open `active-doc-reviews/index.md` only when working on review ledger state.
4. Open individual review files only when the task names that review or requires its findings.

## Avoid

- Do not read all active review files by default.
- Do not read `_archive/` unless specifically researching archived review or batch history.
- Do not use review artifacts as canonical product truth after the fix has been promoted to the owning branch.

## Review Files

Review files are audit artifacts. Implementation agents should consume concise findings and linked owner docs, not the whole historical review trail.
