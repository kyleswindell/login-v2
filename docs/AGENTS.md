# docs AGENTS.md

## Purpose

`docs/` is the canonical documentation root. Use it to find durable product, architecture, planning, database, runbook, reference, and AI-governance truth.

## Read Order

1. Read `00-start-here.md` only when orienting to the whole documentation system.
2. Read the relevant branch `AGENTS.md` before opening branch files.
3. Read the branch `index.md` before opening long canonical docs.
4. Open only the specific canonical file and section required by the task.

## Avoid

- Do not read `docs/_archive/` unless the user explicitly requests archive research.
- Do not read `docs/11-ai/_archive/` unless the task is specifically about archived AI-governance or batch history.
- Do not read `docs/_notes/` unless the user explicitly requests non-canonical notes or the task names a note there.
- Do not traverse Obsidian backlinks as automatic context.
- Do not read every branch index for a narrow implementation task.
- Do not add files under `docs/08-active/` outside approved active-batch workflows.

## Obsidian Coordination

Obsidian links are a discovery map for humans and agents. Treat links as pointers to evaluate, not as instructions to load every linked document.

## Long Context Guidance

When a task points to a long doc, first inspect headings or search within that file. Load only the section that owns the current question.

## Active Workspace

For `docs/08-active/`, follow the root active-workspace rules. Read `batch.md` and the targeted queue item first, then open other active-state files only as required by the current approved workflow.
