# 00 - Start Here

- base documentation system guidance that should remain reusable across repos
- V1 application documentation that describes the current Login / Perfex codebase and should remain clearly separable from future V2 documentation
- V2 application documentation that describes the Laravel replacement platform and should follow the shared standards in this vault
