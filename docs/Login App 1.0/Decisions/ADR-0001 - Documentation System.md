# ADR-0001 - Documentation System

## Status

Accepted as a starting point.

## Decision

Use the Obsidian vault under `documentation/Login App 1.0/` for human-readable application documentation, architecture notes, standards, runbooks, and Codex guidance.

## Rationale

Markdown files are readable by Obsidian, Git, GitHub, search tools, and coding agents. The vault should stay portable by using standard Markdown links alongside Obsidian links.
