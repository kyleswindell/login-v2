# ADR-0002 - Block Based Website Builder Direction

## Status

Proposed.

## Decision

For fresh websites, prefer a structured block-based website builder over direct raw HTML editing.

## Rationale

Structured blocks keep design, responsiveness, security, and tenant consistency under developer control while still allowing admins to edit content, media, metadata, schema, publishing state, section order, and translations.
