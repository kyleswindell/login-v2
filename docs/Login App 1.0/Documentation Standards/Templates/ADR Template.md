# ADR Template

Use this for architecture decision records. Keep ADRs short and link to supporting material when the context is large.

```md
# ADR NNNN - Decision Title

## Status

Proposed | Accepted | Deprecated | Superseded

## Context

Forces, constraints, and why this decision is needed now.

## Decision

We will...

## Consequences

Positive, negative, and neutral effects. Include follow-up actions.

## Links

PRs, issues, related ADRs, reference docs, and release notes.
```
