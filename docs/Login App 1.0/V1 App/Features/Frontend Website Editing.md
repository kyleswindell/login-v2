# Frontend Website Editing

Parent: [[V1 App/Features/Feature Index]] | [Feature Index](Feature%20Index.md)

## Purpose

Document the planned feature that allows website content to be edited from the admin app.

## Current Status

This is a planned/future-oriented V1-adjacent concept note, not a description of a completed current V1 feature.

## Use This Note When

Use this note when you need the product-level answer to:

- what kind of website editing capability is intended
- what the safe editing direction is
- which architecture/module notes hold the deeper planned design

Do not use this note as the main owner of:

- current implemented V1 website editing behavior
- future data-model details
- future sync architecture details

## Planned Direction

Start with a structured page/section/block model. Avoid raw arbitrary HTML editing for normal admin users.
