# .htaccess File

Parent: [[V1 App/Folder Reference/Application Tree Map]] | [Application Tree Map](Application%20Tree%20Map.md)

Path: `application/.htaccess`

## Purpose

This note describes the Apache rewrite file at the V1 app web root.

## Current Behavior

The current file:

- sets `utf-8` as the default charset
- enables `mod_rewrite`
- excludes `index.php`, `resources`, and `robots.txt` from the main rewrite condition
- rewrites non-file and non-directory requests to `index.php?/$1`

## Notes

- This file is part of the web-entry routing layer, but not the owner of tenant DB resolution logic.
- Its main role is front-controller routing for Apache-based deployments.
