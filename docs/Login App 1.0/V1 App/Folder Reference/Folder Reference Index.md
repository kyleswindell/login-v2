# V1 Folder And File Reference Index

Parent: [[V1 App/V1 App Documentation Map]] | [V1 App Documentation Map](../V1%20App%20Documentation%20Map.md)

This section holds the vault's folder-level and root-file reference notes.

In Obsidian, folder placement alone does not create a useful graph. These index notes are the graph entry points that make the file and folder references traversable from [[00 - Start Here]].

## Use This Note When

Use this index when you need the clearest file-system-level answer to:

- which root folders and files make up the V1 Perfex app tree
- where to jump for a folder- or file-specific note
- how the app tree connects back into architecture and module notes

Do not use this index as the main owner of:

- feature behavior
- module responsibilities
- request flow or MVC architecture
