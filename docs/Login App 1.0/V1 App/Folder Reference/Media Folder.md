# Media Folder

Parent: [[V1 App/Folder Reference/Application Tree Map]] | [Application Tree Map](Application%20Tree%20Map.md)

Path: `application/media/`

## Purpose

This note describes the media storage tree used by the V1 application.

## Current Structure

The current repo shows:

- a root media area with placeholder/test files
- a `public/` subtree
- a `tenants/` subtree
- thumbnail/cache-like `.tmb` directories

## Notes

- This folder appears to support both shared/public media and tenant-scoped media.
- The presence of `public/` and `tenants/` suggests it is more than a simple upload mirror.
