# Application Tree Map

Parent: [[V1 App/Folder Reference/Folder Reference Index]] | [Folder Reference Index](Folder%20Reference%20Index.md)

## Purpose

Act as the top-level map for the real Perfex application tree under `application/`.

This note is part of the vault graph, not just a folder list. It should connect the root-file and root-folder notes back into architecture and folder-reference docs so they do not become isolated leaves.

## Use This Note When

Use this note when you need the highest-level map of the real V1 app tree under `application/`.

Do not use this note as the main owner of:

- per-folder implementation details
- per-file behavior details
- module-specific responsibilities
- the overall MVC/request-flow explanation
