# V1 App Documentation Map

Parent: [[00 - Start Here]] | [00 - Start Here](../00%20-%20Start%20Here.md)

## Purpose

This note is the parent map for documentation that describes the current V1 application codebase, features, files, folders, operations, and runtime behavior.

Use this note to keep V1 implementation documentation clearly separated from base documentation system material such as standards, writing guides, Codex guidance, and general documentation rules.

## Use This Note When

Use this note when you need the top-level map of the V1 documentation set.

Do not use this note as the detailed owner of:

- feature behavior details
- file/MVC implementation details
- exact schema, route, or settings references
- operational procedures

## Scope

These sections are V1 application documentation:

- architecture notes that describe the current V1 app
- feature notes for V1 behavior
- module notes for V1 modules
- reference notes for V1 routes, schema, settings, and data models
- file and folder notes for the current V1 repo structure
- V1 operational runbooks and release notes

These sections are not V1-only by default:

- `Documentation Standards/`
- `Standards/`
- `Codex/`
- `Decisions/`

Those base sections should stay reusable across repos unless a specific note clearly documents V1-only behavior.

## Why This Separation Matters

This vault will eventually be migrated into the V2 repo.

When that happens:

- base standards and guidance should remain active
- V1 codebase notes should remain available for reference
- V1 implementation notes should be easy to retire or archive without affecting the base documentation system
