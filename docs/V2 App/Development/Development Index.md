# Development Index

## Purpose

Track implementation progress, corrections, adjustments, and rollout state for active V2 work.

This branch is the chronological companion to planning and canonical system docs.

## Usage Rule

Use this branch to record:

* completed phase milestones
* staging deployment checkpoints
* important corrections or implementation pivots
* follow-up work that should remain visible after code merges

Do not treat this branch as the canonical owner for system behavior. Use:

* `V2 App/Planning/` for sequencing and design intent
* `V2 App/Features/`, `V2 App/Reference/`, and `V2 App/Runbooks/` for canonical system ownership
