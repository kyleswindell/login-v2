## Purpose

This note describes the CodeIgniter framework system folder shipped with the V1 app.

## Notes

- This folder contains framework runtime code, libraries, helpers, and base classes.
- It should generally be treated as framework/vendor code rather than application-owned customization space.
- Per repo rules, changes here should be avoided unless explicitly required.
